# YouJustSay · 你就说

**极简 macOS 语音输入工具：按 Fn，说话，变成文字。** 支持 macOS 14 及以上。

只做语音输入和可选文字整理。不加智能体、知识库或任务执行；无需注册本应用账号，自带 API 密钥，按服务用量付费。

## 为什么选择你就说

如果你只想把话变成文字，工具就该足够简单。

| 产品 | 对只需要语音输入的人 | 你就说的选择 |
| --- | --- | --- |
| [闪电说](https://shandianshuo.cn/docs) | 加入沟通智能体、记忆和技能，功能超出单纯口述输入的需要。 | 只保留识别、整理、上屏，减少功能负担。 |
| [Typeless](https://www.typeless.com/pricing) | 有限额免费版；Pro 月付 US$30，年付折合 US$12/月，持续订阅有成本。 | 无应用订阅费；自带密钥，API 按用量计费。 |
| [豆包输入法](https://ime.doubao.com/pc) | 作者使用体验：需先聚焦文本框，才能开始语音输入。 | 可先说话，再切换应用或输入框；文字就绪时写入当前选中的位置。 |

价格核对于 2026-10-06；豆包聚焦限制为作者体验，可能随版本变化。你就说自动上屏时仍需选中可输入位置，也可选择仅复制。

## 可以用来做什么

回复消息、写邮件、记录想法和待办：把内容说出来，按需整理成可用的文字。

> **口述：**“嗯，明天下午三点讨论新版页面，那个，你先把截图准备好，会议前发给我。”
>
> **轻度润色示意：**“明天下午三点讨论新版页面。请先准备好截图，并在会议前发给我。”

## 开始使用

1. 打开 `YouJustSay.app`，授权麦克风和辅助功能。
2. 在「模型配置」填写服务密钥。豆包需开通录音文件极速版 `volc.bigasr.auc_turbo`；方舟需单独的密钥。
3. 按 Fn 说话，再按 Fn 结束；自动上屏前选中目标输入位置。

按 Esc 取消，识别或整理取消后可在 5 秒内恢复。单次录音最长 5 分钟。按 `⌃⌥⌘S` 打开设置。

## 数据与隐私

密钥保存在本机钥匙串。录音发送至豆包，启用整理时文字发送至所选服务。不保存文字历史，临时录音正常结束后删除。

自动粘贴后恢复原剪贴板；期间新复制的内容会保留。上屏失败时可手动复制结果。
