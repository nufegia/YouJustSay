# YouJustSay · 你就说

极简 macOS 语音输入工具。支持 macOS 14 及以上。

## 使用

1. 打开 `YouJustSay.app`，按引导授权麦克风和辅助功能。
2. 在「模型配置」填写服务密钥，授权钥匙串后自动读取和保存。
3. 将光标放在输入位置，按 Fn 开始，再按 Fn 结束。

可改为按住说话、松开提交，也可自定义快捷键。不足 0.5 秒的录音会自动取消、删除，不进入识别。识别或整理时按 Esc 取消，5 秒内可恢复。单次录音最长 5 分钟。

关闭窗口后继续后台运行。按 `⌃⌥⌘S` 打开设置。Dock 图标、菜单栏图标和登录启动均可配置。

## 模型

- **语音识别：火山·豆包语音。** 需开通录音文件极速版 `volc.bigasr.auc_turbo`，支持 API 密钥或 App ID + Access Token。
- **文本整理：火山· 方舟。** 使用 `doubao-seed-2-1-lite-260915`，需单独填写方舟密钥；也支持自定义 HTTPS OpenAI 兼容接口。
- **整理风格：**基础整理（默认）、轻度润色、高度结构化。基础整理去除无意义的口水词和口吃重复、整理必要标点，尽量保留原话；轻度润色进一步修正语病和措辞；高度结构化按已有内容分段、归类，必要时生成标题和列表。各风格均按语境保留有效的肯定、指代、不确定性和强调，不执行或回答口述中的请求。可关闭整理，也可从菜单栏切换风格；升级保留已保存的风格选择。

界面支持英语、简体中文和繁体中文。识别语言、中文输出偏好独立设置，默认自动。

「模型配置」中的语音识别和文本整理密钥输入框右侧均提供「测试」按钮。语音测试发送内置短音频，无需麦克风权限；文本测试用固定短句调用当前模型及接口。成功表示当前配置可以正常调用，失败显示错误；修改密钥或接口配置后清除旧结果。测试使用服务的正常 API，按服务方规则计费。

## 输入与数据

上屏方式：剪贴板自动粘贴、直接键入、仅复制。录音和识别期间可以切换应用或输入框，文字准备好后写入当前选中的位置。

自动粘贴临时使用剪贴板，发送 ⌘V 后等待约 0.75 秒恢复原内容（包括图片、文件引用等格式）；期间若发生新的复制，则保留新内容。特别慢的应用可能延迟读取剪贴板，可改用直接键入。直接键入不会修改剪贴板。自动上屏失败或写入途中焦点改变时，保留全文并显示「复制上次结果」按钮，由你主动复制；若已有部分文字写入，手动粘贴前请检查，避免重复。仅复制、主动复制结果会替换剪贴板内容。

录音发送至豆包；启用整理时，文字发送至所选模型服务。密钥统一保存在本机钥匙串，不迁移旧版分散条目。不保存文字历史，上次结果仅驻留内存；临时录音正常结束后删除。

## 开发

使用 Swift 6、SwiftUI、AppKit。构建需要附带 Icon Composer 的 Xcode 26 或更新版本。

```sh
./script/build_and_run.sh          # 构建并启动
./script/build_and_run.sh --build  # 仅构建
swift test                       # 自动测试
```

产物：`dist/YouJustSay.app`。当前试用版为临时签名，未公证；重新构建后可能需要再次授权。方舟真实调用、硬件快捷键、跨应用输入和登录启动仍需实机验收。

图标源文件：`Resources/AppIcon.icon`。[生成记录](docs/icon-design.md) · [亮色预览](docs/icon-light.png) · [暗色预览](docs/icon-dark.png)

## 设置与关于

设置窗口采用顶部图标分页：通用、录音交互、模型配置、权限、关于。关于页从应用包读取版本信息，提供数据说明、在 Finder 中显示应用及复制应用版本和系统信息的功能。

测试版重编译后，如果系统辅助功能开关已打开，应用却显示未授权，可在「权限」页点击「修复授权」。这会仅清除你就说的旧辅助功能授权，并打开系统设置供重新允许访问；其他应用及麦克风授权不受影响。返回应用后自动检查，若仍未生效，请退出并重新打开。清除失败时可用「在访达中显示当前应用」找到正确的应用包，手动重新添加。

默认打包使用临时签名，重编译后可能需要重新授权。若已有代码签名证书，可通过 `YOUJUSTSAY_SIGNING_IDENTITY` 指定证书名称或指纹后运行构建脚本；后续版本持续使用同一身份签名，有助于保留系统授权。脚本不会自行创建证书或修改系统信任设置。

## GitHub 分发与更新

当前版本没有自动更新组件，下载新版本后需退出旧应用，再替换安装；应用设置和钥匙串密钥不存放在应用包内。临时签名的构建替换后仍可能需要重新授权。

通过 GitHub 开源和分发可以支持应用内更新，但仅发布 GitHub Release 不会让应用自动更新。可接入 [Sparkle 2](https://sparkle-project.org/documentation/)，将更新包放在 GitHub Releases，将固定地址的 `appcast.xml` 更新源托管于 GitHub Pages 等 HTTPS 服务，并递增构建号。更新包需使用 Sparkle 的 EdDSA 密钥签名，私钥不得提交到开源仓库。面向公众分发建议使用 Developer ID 签名并完成 Apple 公证。

GitHub 仓库：[nufegia/YouJustSay](https://github.com/nufegia/YouJustSay)。当前仓库为私密仓库，关于页尚未添加仓库或下载链接。
