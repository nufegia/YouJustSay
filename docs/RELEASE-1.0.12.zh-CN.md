# YouJustSay · 你就说 1.0.12

- 新增 Google Gemini 录音转文字和文本整理，两处共用 API Key，安全保存在钥匙串中。
- Gemini 文本整理默认使用更轻量的 Gemini 3.5 Flash-Lite，同时提供 Hydrogen、Argon、Carbon、3.8 Flash 和自定义模型。
- 供应方顺序统一为 OpenAI、Gemini、字节，支持分别选择识别和整理供应方。
- 保留独立连接测试；仅支持录音结束后转文字，不包含实时识别。

适用于 Apple 芯片 Mac，macOS 14 或更新版本。应用使用 Apple Developer ID 签名并经过苹果公证，支持应用内检查更新。
