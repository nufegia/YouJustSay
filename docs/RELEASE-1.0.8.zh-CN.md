# 你就说 1.0.8

- 换上全新 Y 形图标：流动的线条与青色点缀呼应 YouJustSay，分别提供亮色、暗色外观。
- 应用与官网统一使用确认后的 1254 × 1254 独立生图原稿，不使用方案图裁片，不重绘或放大。
- 修复白色官网跟随系统深色模式而显示黑底图标的问题，网页统一使用亮色版。
- **继续采用 Apple Developer ID 签名并通过苹果公证**，安装后可正常双击打开。首次运行仍需按系统提示确认打开，并授权麦克风和辅助功能。

适用于 macOS 14+、Apple 芯片。已有用户可在应用内检查更新，或下载 DMG 手动安装。更新包继续通过 Sparkle Ed25519 签名验证。
