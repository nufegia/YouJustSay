# 你就说 1.0.7

- 全新扁平应用图标：以简洁的对话轮廓和三段声波表达“开口说话”，分别提供亮色与暗色外观。
- **已完成 Apple Developer ID 签名与苹果公证**：应用使用 Apple 颁发的开发者证书签名，经过苹果公证服务检查，并附有公证凭证。下载安装后可正常双击打开，无需手动选择“仍要打开”。
- 官网同步更新图标、安装说明和签名公证信息。

适用于 macOS 14+、Apple 芯片。首次运行仍需按系统提示确认打开，并授权麦克风与辅助功能。苹果公证属于安全检查，不等同于 Mac App Store 上架审核。

已有版本可在应用内检查更新，也可下载 DMG 手动安装。更新安装包继续使用 Sparkle Ed25519 签名验证。
