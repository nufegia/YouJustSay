# 安装 YouJustSay · 你就说

适用于 Apple 芯片（M1 及更新机型），macOS 14 或更新版本。

1. 打开 DMG，将 YouJustSay 拖入 Applications（应用程序）。
2. 在应用程序中打开 YouJustSay，按系统提示确认打开。
3. 按应用提示授权麦克风和辅助功能；必要时退出并重新打开应用。
4. 填写豆包语音密钥；启用文本整理时填写方舟密钥，或配置自定义 OpenAI 兼容接口。点击“测试”验证配置。
5. 按 Fn 开始说话，再按 Fn 结束，按 Esc 取消。按 ⌃⌥⌘S 打开设置。

此应用使用 Developer ID 签名并经过苹果公证。受管理电脑可能有额外限制。
可在“关于”页或应用菜单中检查更新。服务费用由所选服务商按其规则收取。
密钥存于本机钥匙串，音频及文字发送给所选服务处理；应用不保存文字历史，临时录音正常结束后删除。
