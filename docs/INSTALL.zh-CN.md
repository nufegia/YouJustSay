# 安装 YouJustSay · 你就说

适用于 Apple 芯片（M1 及更新机型），macOS 14 或更新版本。当前发行包不支持 Intel Mac。

1. 从 https://github.com/nufegia/YouJustSay/releases/latest 下载 DMG。
2. 打开 DMG，将 YouJustSay 拖入 Applications（应用程序）。
3. 在应用程序中打开 YouJustSay。如果 macOS 提示无法验证开发者或未公证，打开「系统设置 → 隐私与安全性」，找到 YouJustSay 的拦截提示，点击「仍要打开」，验证身份并确认。
4. 按应用提示授权麦克风和辅助功能。如授权后仍无效，请退出并重新打开应用。
5. 填写自己的豆包语音密钥（录音文件极速版）；启用文本整理时填写方舟密钥，或配置自定义 OpenAI 兼容整理接口。点击「测试」验证配置。服务费用由所选服务商按其规则收取。
6. 按 Fn 开始说话，再按 Fn 结束。可在识别完成前选择目标输入框。设置也支持按住说话、直接键入和仅复制。

按 Esc 取消；识别或整理取消后，5 秒内可恢复。按 ⌃⌥⌘S 打开设置。

此发行版采用本地临时签名，未使用 Developer ID 签名，也未经过苹果公证。上述放行步骤适用于开发者身份或公证提示；受管理电脑可能有额外限制。如果系统报告恶意软件，请勿强行绕过。
苹果说明：https://support.apple.com/en-us/102445

更新：退出应用后，用新版本替换应用程序中的旧版本。应用没有内置自动更新。必要时重新检查辅助功能授权。

密钥存于本机钥匙串，音频及文字发送给所选服务处理。应用不保存文字历史，临时录音正常结束后删除。
