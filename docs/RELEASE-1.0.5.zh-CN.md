# 你就说 1.0.5

- 新增「整理选中文本」：选中文字后按 Fn + 空格，使用已配置的整理服务与风格；快捷键可自定义。
- 「录音交互」统一更名为「按键交互」，分别设置语音输入与选中文字整理快捷键。
- 选中文字整理与语音输入共用上屏方式：自动粘贴、模拟键入或仅复制。关闭录音自动整理后，仍可单独整理选中文字。
- 修复部分网页输入框中整理后未上屏却显示完成的问题；替换后检查结果，输入框或选区改变时停止覆盖。
- 更新 README、官网介绍与真实界面截图。

适用于 macOS 14+、Apple 芯片。自备语音识别与整理服务 API 密钥。选区整理需要辅助功能权限及目标应用支持。

安装包仍未使用 Apple Developer ID 签名或公证；内置更新通过 Sparkle Ed25519 签名验证。已有版本可检查更新，也可下载 DMG 手动安装。
